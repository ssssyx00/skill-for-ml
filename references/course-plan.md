# 五天首轮学习与后五天复习

只在计划、换日、检查覆盖或调整进度时读此文件。以下为初始课程路线，不是每轮回复模板；用户指定的新顺序与时间优先。按零基础解释，不凭项目经历省去基础。

此路线依据本次已查看的 11 份课件整理，只提供导航。开始教某一小节时仍需读取用户实际上传的版本，核对标题、公式、例题、学习目标与真实页码；新版本与此表冲突时以新版本和用户要求为准。

## 时间预算

- 每天暂按约 8 小时有效学习，上午 2.5、下午 3、晚上 2.5 小时；不把全天都当成高效时间，不要求熬夜。
- 前 20 分钟回顾昨日、末 20 分钟记录卡点，含在预算中；复习可用简短回忆提纲，不强制测验。
- 第五天晚上留作补进度。每天结束时比较实际覆盖与目标；先压缩重复和非必要扩展，再调整顺序，不能通过跳过必要基础伪装达标。
- 第一轮只做“核心概念、关键公式、一个例子、具体卡点”短笔记，不逐页誊抄或双语全文翻译。

## 自动深度判断的课程示例

随真实材料、用户卡点和要求修正，不把下表当考试预测或固定跳过清单。

| 内容 | 常见决定 | 原因及最低理解要求 |
|---|---|---|
| 条件概率、加权平均 → GMM/EM | 现在补清 | 它们决定软分配与 E/M 更新的含义，必须能读懂各项及归一化 |
| 链式法则 → 反向传播 | 现在补清 | 不能只背梯度公式；至少走通一个小网络，区分求梯度和更新参数 |
| 熵/条件熵 → 信息增益 | 本轮讲清并走例题 | 从不确定性的直觉接到公式，理解为什么选择信息增益大的分裂 |
| AdaBoost 更新 | 本轮理解和使用，必要时补推导 | 知道错分样本如何改变权重、分类器如何加权；推导是否加深看课件要求与当前卡点 |
| EM 的 Jensen 下界长证明 | 视依赖决定；细节可后补 | 先讲为什么需要替代难优化的目标、E/M 如何配合；若不会 E/M 是概率基础问题，不能一起略过 |
| PCA | 现在补够线性代数与计算 | 理解中心化、方差、特征方向、投影；若只剩最优性长证明可记录后补 |
| RNN/LSTM/Transformer | 按课件深度学结构和核心运算 | 不能只背名称，也不自动扩展到实现完整大模型或研究论文 |
| Regret/UCB | 本轮理解含义与代入 | 区分即时奖励和累计损失、理解探索项；不自动扩展到遗憾下界证明 |
| Bellman 方程 | 现在讲清递归含义和基础计算 | 将“眼前奖励 + 折扣后的未来价值”接到期望与状态转移，跟完一个策略评估例题 |

## 第 6–10 天：整个学期的第二轮

不要把这五天再次全部分给 11–21 讲。先用已有材料建立全学期覆盖表；1–10 讲若未提供，标为材料未核实，索取材料/目录这一个关键缺口，不猜章节名称。

按“阻断性基础或误解 → 核心计算和课件明确要求 → 易混方法对照 → 非阻断长证明”安排复习。结合前半学期真实覆盖量分配时间，不能仅凭讲数机械对半。

只有用户进入练习模式才做短测；有证据已会的内容缩短复习，错题针对错误步骤补讲。若核心理解明显不足，坦诚调整目标或时间，不承诺十天必然熟练或保证考试成绩。
