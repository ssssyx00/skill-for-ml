# 按需复习工具

仅在用户明确要求对应输出时读取；不把这些功能加入每次讲解的固定步骤。本 skill 内置 PDF/PPTX 索引和学习记录脚本（见 scripts.md），没有网站生成器或 Anki 同步服务；其他功能使用环境实际可用工具。

| 请求 | 默认范围与输出 |
|---|---|
| 知识地图/总结 | 当前讲约 5–10 个概念，标前置依赖、核心内容和已讲/待补状态；优先紧凑表格，避免重写全章 |
| 闪卡 | 每讲先做 5–8 张；术语含义、方法差异、公式用途和关键条件；答案和真实来源定位配对，不把每个例题数字变成记忆题 |
| 考我/练习 | 默认当前模块 2–3 题，明确用户要几题就按要求；先出题，等答案再批改，主要纠正错误步骤；没有回答就不虚构得分 |
| 带答案练习 | 题目和答案分区；标明自拟题及参考的课件位置；看过答案不能记录为独立通过 |
| 模拟考试 | 根据用户提供的范围、题型、时长组织；缺少考试说明就明确“自拟练习”，不冒充真实考试结构或押题 |
| 易混概念 | 小对照表，如 KNN/K-means、Bagging/Boosting、PCA/ICA、V/Q；解释差别来自哪里，不只列名词 |
| 笔记/PDF 导出 | 按请求范围导出；保留必要解释、关键公式、例题、卡点和来源，不逐页全文翻译或自动扩为长教材 |
| 交互页面/离线学习页 | 仅生成用户要求范围的地图、笔记、翻卡/练习和进度功能；先说明实际可实现的范围，利用环境已有制作工具，不默认部署或发布 |

页面若实际生成，检查公式显示、答案显隐、来源链接和进度保存；离线要求下不依赖 CDN。无法完整验证时写清限制。只有用户要求的功能才制作，不自动搭建完整网站或调用来源项目脚本。

复习建议可在下次学习开头、隔几天和第二轮安排短回顾；根据错误调整，不强行套用超过当前十天窗口的长周期。建议回顾不等于设置提醒，用户明确要求未来提醒时才使用宿主可用的自动化能力。
